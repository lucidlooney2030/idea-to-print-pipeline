# Generators registry

Each file here is a registry entry for one parametric OpenSCAD project that idea-to-print can drive. The skill reads these instead of hard-coding any single repo.

See `skills/idea-to-print/references/generator-contract.md` for the schema and rules.

Current entries:

- `serpentine.yaml.example` — dual-magnet axial generator (worked example; copy to `serpentine.yaml` to activate).
