# Print and debrief

1. Print the coupon from the same parameters.yaml.
2. Material: PETG/ABS/ASA/nylon for rotors. Not PLA.
3. Magnets last, one at a time, spacers in the gap.
4. After bench: RPM, Voc, gap, turns, wiring into DEBRIEF.md.
5. If Voc slope vs RPM disagrees with the estimate, change Bg assumption or the hardware — do not add a new GitHub repo.
